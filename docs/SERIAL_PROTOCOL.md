# ПРОТОКОЛ ОБМЕНА: БОРТОВОЙ ПК (ROS 2) ↔ ARDUINO MEGA PRO

Физика: UART, 115200 8N1. У каждого из 4 модулей свой порт
(`/dev/rus_module_fl|fr|rl|rr` через udev-правила, либо `/dev/ttyUSB0..3`).
Контроль целостности — **CRC16/Modbus** (полином `0xA001`, инициализация `0xFFFF`),
байты контрольной суммы передаются в порядке **big-endian**.

---

## 1. Кадр команды: ПК → микроконтроллер (10 байт)

| Смещение | Поле | Тип | Значение |
| :---: | :--- | :--- | :--- |
| 0 | `SYNC0` | u8 | `0xAA` |
| 1 | `SYNC1` | u8 | `0x55` |
| 2 | `MODULE_ID` | u8 | 1=FL, 2=FR, 3=RL, 4=RR |
| 3–4 | `STEER_CDEG` | i16 BE | Целевой угол поворота модуля, **сотые доли градуса** (±327.67°) |
| 5–6 | `TRACTION_PWM` | i16 BE | Задание тяги, **−1000…+1000** (−1000 = полный назад) |
| 7 | `FLAGS` | u8 | бит0 = `ENABLE` (подача момента), бит1 = `HOME` (запуск хоминга) |
| 8–9 | `CRC16` | u16 BE | CRC16 от байт 0–7 |

Пример (включить модуль 1, угол 45.00°, тяга +500):
`AA 55 01 11 94 01 F4 01 <CRC16>`

Поведение МК по кадру:
- перевод угла в шаги: `step = угол_град × 12000 / 360` (микрοшаг 1/8, редукция 7.5);
- `TRACTION_PWM` → скважность 6-тактной коммутации собственного BLDC-моста;
- `FLAGS.bit1 = 1` → запуск процедуры хоминга до концевика нулевого азимута;
- каждый валидный кадр сбрасывает сторожевой таймер МК.

**Сторож МК:** если валидных кадров нет дольше **300 мс**, модуль снимает
момент с шаговика и обесточивает мотор-колесо. Частота отправки команд
из `module_bridge_node` — не реже 20 Гц.

## 2. Кадр телеметрии: микроконтроллер → ПК (16 байт, 20 Гц)

| Смещение | Поле | Тип | Значение |
| :---: | :--- | :--- | :--- |
| 0 | `SYNC0` | u8 | `0xBB` |
| 1 | `SYNC1` | u8 | `0x44` |
| 2 | `MODULE_ID` | u8 | 1..4 |
| 3 | `STATUS` | u8 | бит0 = `ENABLED`, бит1 = `HOMED`, бит2 = `FAULT` |
| 4–5 | `STEER_CDEG` | i16 BE | Фактический угол модуля, сотые доли градуса |
| 6–7 | `ENC_DELTA` | i16 BE | Приращение тиков энкодера колеса с прошлого кадра (со знаком) |
| 8–9 | `PWM_ACTUAL` | i16 BE | Текущая скважность тяги −1000…+1000 |
| 10–11 | `VBAT_CV` | u16 BE | Напряжение шины, **сантиВольты** (3840 = 38.4 В) |
| 12–13 | `CURRENT_MA` | u16 BE | Ток мотор-колеса, мА (шунт 5 мОм) |
| 14–15 | `CRC16` | u16 BE | CRC16 от байт 0–13 |

Парсер на стороне ПК (`rus_slam_base/protocol.py`) побайтно ищет заголовок
`0xBB 0x44`, читает 16 байт и проверяет CRC; при ошибке кадр отбрасывается,
поиск синхронизации продолжается.

Преобразование тиков в метры (параметр `encoder_ticks_per_rev`):
```text
dist_m = ENC_DELTA × 2πR / ticks_per_rev
```

## 3. udev-правила (стабильные имена портов)

Пакет `rus_slam_bringup` содержит `udev/99-rus-slam.rules`: порты привязываются
к физическим USB-портам и получают симлинки `rus_module_fl`, `rus_module_fr`,
`rus_module_rl`, `rus_module_rr`. Установка:

```bash
sudo cp ros2_ws/src/rus_slam_bringup/udev/99-rus-slam.rules /etc/udev/rules.d/
sudo udevadm control --reload-rules && sudo udevadm trigger
```

## 4. Лидар ЛДС-01 (360°, 5–10 Гц)

Лидар подключается отдельным UART/USB-UART мостом (по умолчанию
`/dev/rus_lidar`, 230400 бод). Драйвер `lds01_driver_node` реализован с
настраиваемым парсером кадра (заголовочный байт, число точек на кадр,
метод контрольной суммы) — семейство кадров компактных UART-лидаров
(синхро-байт + пакеты точек дальность/интенсивность + углы начала/конца).
Точная таблица полей вносится в конфиг `lidar.yaml` после получения
паспорта конкретного экземпляра; выходные данные узла стандартны —
`sensor_msgs/LaserScan` в `frame_id=lidar_link`.
