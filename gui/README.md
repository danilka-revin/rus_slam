# Диспетчер автономной логистики — пульт робота (Web GUI)

Веб-пульт робота-курьера НТЦ АВТОВАЗ в раскладке диспетчерского экрана:

```
┌────────────────────────────────────────────────────────────────────────────┐
│ НТЦ АВТОВАЗ        [ КАРТА | КАМЕРА ]      Демо • 95% • 0.0 км/ч • LiDAR  │
├──────────────┬──────────────────────────────────────┬──────────────────────┤
│ ПАНЕЛЬ ЗАКАЗОВ│        КАРТА ЛИДАР                  │ МОНИТОРИНГ И ЗРЕНИЕ  │
│ A: КТП  [↔]  │  дороги, здания, зона, маршрут,     │  (камера CAM-01 +    │
│ B: Склад     │  робот RB-01, метки A/B, pan/zoom   │   детекции YOLO)     │
│ [ОТПРАВИТЬ]  ├──────────────────────────────────────┤ РАСПОЗНАВАНИЕ ОБ-ОВ  │
│ [E-STOP]     │  СХЕМА ЗАДАНИЯ:                     │  (список с conf)     │
│ СХЕМА ЗАДАНИЯ│  А→Б → открыть → ждать →            │ ЖУРНАЛ СОБЫТИЙ       │
│ (блоки миссии│  закрыть → ждать → на А → ожидание  │  (ROSOUT-лог)        │
└──────────────┴──────────────────────────────────────┴──────────────────────┘
```

Дизайн-язык перенесён из [ZMK Vision Console](https://github.com/danilka-revin/zmk-videoanalytics)
(токены, темы, панели, сегментные вкладки, LIVE/REC-бейджи), под раскладку
диспетчерского макета (тёмная тема, циановый акцент).

## Возможности (v0.2)

- **Вкладки «Карта / Камера» по центру шапки** (клавиши `1` / `2`, `K` —
  настройки, `Space` — E-STOP): карта — главное окно, вкладка камеры
  разворачивает её на весь центр.
- **Панель заказов**: точки A/B (КТП, Склад, Администрация, Зона
  тестирования), смена местами, «Отправить задание», экстренная остановка
  (E-STOP), статус робота и отсека. Клик по точке на карте назначает пункт B.
- **Схема задания — миссия как программа из блоков**: движение А → Б →
  открыть отсек → ожидание → закрыть отсек → ожидание → возврат на А →
  ожидание задания. Активный блок подсвечен с прогресс-баром, пройденные —
  с отметкой; тайминги действий/ожиданий настраиваются.
- **Карта лидара** (canvas, без зависимостей): сдвиг ЛКМ/пинч, зум колесом
  к курсору / пинчем / кнопками (+/−/вписать/следование), сетка 10/50 м,
  дорожная сеть с осевыми, здания (СКЛАД №2, АДМИНИСТРАЦИЯ, КТП),
  штрихованная зона тестирования, маршрут миссии (активное плечо ярче),
  метки A/B, робот RB-01 с **лидаром ЛДС-01 в носовой точке** (сверху спереди
  по центру, совпадает с URDF `lidar_joint` x=0.32) и вращающимся лучом,
  шлейф, облако точек скана, масштабная линейка, координаты X/Y/θ в шапке.
- **Мониторинг и зрение**: камера CAM-01 — демо-рейкастинг от позиции робота
  (вид реагирует на движение/поворот) с bounding-box'ами детекций
  (STOP sign, Pedestrian, Crosswalk, Traffic light) и conf; при заданном URL
  (HLS/WebM) — реальное `<video>`. REC-бейдж, время, FOV 87°.
- **Распознавание объектов (YOLOv-8 demo)**: список активных детекций с
  уверенностью; **журнал событий (ROSOUT)**: светофоры (зелёный/жёлтый/
  красный), препятствия, события миссии и E-STOP.
- **Кастомизация**: тема (светлая/тёмная/авто), акцент (5 пресетов),
  шрифт S/M/L, стиль карты, следование за роботом, сетка/шлейф/скан,
  масштаб метки, тайминги миссии, качество камеры, оверлеи, URL потока,
  сброс. Всё в localStorage.
- **Демо-симулятор** (10 Гц): робот 3.5 м/с (≈12.6 км/ч) по графу дорог
  (Дейкстра), автопатруль, полный цикл миссии, E-STOP, отсек, батарея,
  одометр; детектор объектов с циклом светофора. Через 2 с после запуска
  автоматически отправляется демо-задание КТП → Склад.

## Запуск

Одним скриптом — на **Ubuntu** и на **Windows** (скрипт сам проверит Node.js
и поставит зависимости при первом запуске):

```bash
# Ubuntu / Linux
./start.sh                 # http://localhost:5173
./start.sh --prod          # прод-сборка + просмотр (порт 4173)
./start.sh --port 8080     # другой порт
```

```bat
:: Windows (двойной клик или из cmd)
start.bat                 rem http://localhost:5173
start.bat --prod          rem прод-сборка + просмотр (порт 4173)
start.bat --port 8080     rem другой порт
```

Вручную:

```bash
cd gui
npm install
npm run dev        # http://localhost:5173 (bind 0.0.0.0)
npm run build      # typecheck + прод-сборка в dist/
```

Полное описание пульта (раскладка, панели, горячие клавиши, кастомизация,
симулятор, прод-сборка, мост ROS 2) — в [`docs/GUI.md`](../docs/GUI.md)
([PDF](../docs/GUI.pdf)).

## Структура

```
src/
  lib/
    territory.ts      — территория: точки, дороги, здания, зона,
                        raycast (здания/препятствия/граница), Дейкстра
    simulator.ts      — робот: кинематика, конечный автомат миссии
                        (движение/отсек/ожидания), E-STOP, скан лидара
    detect.ts         — демо YOLOv8: цикл светофора, детекции с box/conf
    mapRender.ts      — рендер карты (pan/zoom-трансформ, маршрут, робот)
    cameraRender.ts   — рейкастинг вида с камеры + оверлей детекций
    settings.ts       — настройки + персистентность (localStorage)
  components/
    Header.tsx        — шапка: бренд, вкладки Карта/Камера, чипы телеметрии
    DispatchPanel.tsx — панель заказов (A/B, отправка, E-STOP, статус)
    SchemePanel.tsx   — схема задания: блоки миссии с прогрессом
    MapPanel.tsx      — карта: pan/zoom/pinch, клик по точкам, легенда
    CameraFeed.tsx    — лента CAM-01 (демо-рендер / video)
    VisionPanel.tsx   — правая колонка: зрение + распознавание + журнал
    Customizer.tsx    — панель кастомизации
```

## Дальше (мост ROS 2)

`simulator.ts` / `detect.ts` — изолированные источники данных. Следующий
шаг — узел-мост (`ros2_ws/src/rus_slam_gui_bridge`): `tf2` (pose),
`sensor_msgs/LaserScan`, `nav_msgs/OccupancyGrid`, детекции (YOLO-узел),
камера (WebRTC/MJPEG) → WebSocket, и GUI переходит с демо-режима на живые
данные без изменения интерфейсов.
