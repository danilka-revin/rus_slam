# Пульт RUS SLAM — ZMK Vision редизайн

Веб-панель управления роботом-курьером 4WIS/4WID в визуальном языке [ZMK Vision](https://github.com/danilka-revin/zmk-videoanalytics): тёмный сайдбар `#101b17`, акцент `#d5ff45`, светлая рабочая зона `#f3f5f7`.

## Что сделано по запросу (одна вкладка, слева панель)

**Левая панель (340px, ZMK стиль):**
- Бренд RUS SLAM + 1 вкладка «Пульт управления» с live-dot
- **Модель робота**: canvas `#chassis` 280×280 — вид сверху шасси 4WIS с 4 колесами, угол поворота каждого колеса в градусах подписан у колеса, лидар-шайба с sweep-линией, индикация груза
- Джойстик + HUD vx/vy/wz/yaw
- **Батарея**: круглый прогресс SOC в %, напряжение В, ток А, цель заряда %, bar, статус. Индикатор зарядки `⚡ ЗАРЯДКА` — появляется с пульсацией и свечением когда `state.charging=true`, круг становится зеленым
- **Модули**: 4 карточки FL/FR/RL/RR — большой угол поворота в градусах (`22.5° поворот`), бары STEER/RPM/TEMP, HOMED/SEEK, тип привода
- Управление: краб, скорость, зазор, груз, заряд до, хоминг, на базу, сигнал
- Статус связи UART×4 20 Гц CRC16

**Центр — карта LiDAR SLAM:**
- Большая карта, которую построил робот (occupancy grid 0.12м), лидар 360° 180 лучей, след, путь A*, точки P, станции А/Б/база, сетка 1м
- Панель инструментов: автоскан, старт маршрута, пауза, пропуск, на базу, цикл, сброс, к роботу, снимок
- Route-bar: сохранение групп точек в localStorage
- Events strip + программа доставки А→Б компактно под картой

**Справа от карты — две камеры:**
- `CAM-F · ВПЕРЕД` — canvas `#cam` 640×360, raycast рендер склада, станции как маркеры, перекрестие, детекция препятствий спереди
- `CAM-R · НАЗАД` — canvas `#cam-rear` 640×360, аналогично сзади, дистанция сзади и статус
- Мини-лидар 360° сырой скан + журнал

Симуляция: одометрия, лидар, камера, модули, FSM, e-stop, зарядка, физика корпуса с коллизиями. Клавиши: WASD/стрелки, Q/E — краб, пробел — стоп, H — хоминг, клик по карте — точка, ПКМ — удалить.

Откройте `index.html` напрямую или `python3 -m http.server 8080`.
