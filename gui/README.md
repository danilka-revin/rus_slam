# RUS SLAM — Профессиональный пульт для судей НТЦ АВТОВАЗ

Промышленный HMI в стиле ZMK Vision Pro: тёмная тема, акцент лайм #d5ff45, плотная компоновка для операторов логистики.

## Для судей — почему это удобное реальное приложение

**Левая панель — всё под рукой, без вкладок:**
- **Модель шасси 4WIS/4WID 250кг** — 320×320 топ-вид с тенью, сеткой, лидар-шайбой и sweep-линией. У каждого колеса подписан угол поворота в градусах прямо на модели + отдельные dial-карточки с большими цифрами. Сразу видно крабовый ход.
- **Питание LiFePO4 12S3P 714Вт·ч** — круг SOC 0-100% с анимацией, напряжение 51.2В, ток, цель заряда, остаток часов, BMS OK. При зарядке: бейдж «ЗАРЯДКА 78% → 80%» пульсирует, круг светится зелёным, иконка ⚡ мигает, bar анимирован. Судья сразу понимает заряжается или нет.
- **Приводы — угол в градусах** — 4 карточки FL/FR/RL/RR: большой циферблат steer с градусами (от -90 до +90), RPM BLDC, TEMP NTC, статус HOMED/SEEK, dot OK/WARN. Легенда цветов.
- **Быстрое управление** — тумблеры (краб, маяк, замок отсека), слайдеры с шкалой (скорость 1-5 м/с, зазор 0.4-1.4м, груз 0-250кг, заряд до 40-100%), кнопки хоминг/на базу/сигнал.
- **Здоровье системы** — 6 плиток LiDAR/CAM-F/CAM-R/BMS/BLDC/NEMA23 с зелёными точками.
- **Связь** — UART×4 20Гц CRC16, ROS2 Humble, уровень сигнала барами, оператор смены.

**Центр — карта SLAM, которую построил робот:**
- На всю высоту, occupancy grid 0.12м, сетка 1м, след, путь A*, точки P, станции А/Б/база, кольца лидара 2/4/6/8/10м. Pan/zoom, клик = точка, ПКМ удалить.
- Тулбар: автоскан склада, старт маршрута, пауза, пропуск, на базу, цикл, сброс, к роботу, снимок.
- Route-bar с сохранением групп в localStorage.
- Events лента с цветами ok/warn/err/nav.
- Footer карты: координаты, легенда проезд/стеллаж/неизвестно/путь A*, масштаб.
- Под картой — программа доставки А→Б: чип-кнопки площадок, шаги, очередь с прогрессом, подтверждение груза.

**Справа от карты — две камеры:**
- **CAM-F вперёд** 640×360 30FPS — raycast склада, маркеры станций, перекрестие, timestamp ROS2, REC, детекция препятствий, дистанция вперёд, рысканье.
- **CAM-R назад** 640×200 — зеркало, контроль зоны, дистанция сзади, статус, скорость.
- **LiDAR 360° сырой скан** — полярная диаграмма, свободная зона, препятствия красным, робот лайм, сетка.
- **Журнал ROS2** — 200 строк, уровни ok/warn/err, время, очистка.

**Топбар и метрики:**
- Хлебные крошки, заголовок с бейджем 250кг, статуслайн TELEOP/AUTO/E-STOP + FSM, sys-chips LiDAR/CAM-F/CAM-R/АКБ, E-STOP большой красный с тенью.
- 6 метрик: одометрия (путь, x/y/yaw, тренд), скорость км/ч, безопасность гейт, миссия точки, груз кг, SLAM % изучено с баром.
- Нижний бар с подсказками клавиш WASD/QE/Space/H.

**Управление:** WASD/стрелки вперёд/поворот, Q/E стрейф в крабе, пробел стоп, H хоминг, мышь стик, карта клик.

Откройте `index.html` или `python3 -m http.server 8080`.
