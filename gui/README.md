# Pульт робота «РУС-SLAM» (Web GUI)

Веб-пульт для робота-курьера НТЦ АВТОВАЗ: окно карты SLAM с управлением
(pan / zoom), окно «что видит робот» (камера) и полноценная кастомизация.

Дизайн перенесён из [ZMK Vision Console](https://github.com/danilka-revin/zmk-videoanalytics)
(только визуальный язык: токены цвета, тёмная/светлая темы, лаймовый акцент
`#d5ff45`, сайдбар `#101b17`, панели 11px, сегментный тумблер, LIVE-бейджи).

## Возможности (v0.1)

- **Тумблер «Карта / Камера» по центру шапки** — быстрое переключение окон
  (клавиши `1` / `2`, `K` — кастомизация).
- **Карта SLAM** (canvas, без внешних зависимостей):
  - сдвиг — ЛКМ / палец; масштаб — колесо / пинч (к точке курсора);
  - двойной клик — приближение; кнопки `+ / − / вписать / следование за роботом`;
  - сетка в метрах (1 м / 5 м), масштабная линейка, компас;
  - робот 0.75×0.60 м с 4 модулями, **лидар ЛДС-01 — сверху спереди по центру**
    (совпадает с URDF: `lidar_joint` x=0.32 м), вращающийся луч скана;
  - шлейф пройденного пути, облако точек скана, пульсирующая цель.
- **Окно камеры**:
  - демо-режим — рейкастинг «от глаз робота» по той же сетке карты
    (вид реагирует на движение и поворот, как у реального потока);
  - при заданном URL (HLS/WebM) — обычное `<video>`;
  - LIVE/DEMO-бейдж, время, сетка-сетка, HUD-уголки, снимок (PNG),
    полноэкранный режим.
- **Кастомизация** (панель справа, `K`): тема светлая/тёмная/авто,
  акцентный цвет (5 пресетов), размер шрифта S/M/L, стиль карты,
  следование за роботом, сетка/шлейф/скан, масштаб метки, качество рендера
  камеры, оверлеи камеры, URL потока, сброс к дефолту.
  Всё сохраняется в `localStorage`.
- **Демо-симулятор** (10 Гц): крабовая кинематика 4WIS (корпус поворачивается
  к направлению движения с запаздыванием — робот «крабом» проходит повороты),
  360°-скан лидара DDA-лучами из носовой точки, батарея, одометр.

## Запуск

```bash
cd gui
npm install
npm run dev        # http://localhost:5173 (бесит на 0.0.0.0)
npm run build      # typecheck + прод-сборка в dist/
```

## Структура

```
src/
  lib/
    settings.ts       — настройки + персистентность (localStorage)
    simulator.ts      — карта-манеж, робот, скан лидара (демо-источник данных)
    mapRender.ts      — рендер карты: трансформ pan/zoom, робот с лидаром
    cameraRender.ts   — рейкастинг вида с камеры
  components/
    Sidebar.tsx       — сайдбар (навигация, статус, оператор)
    Header.tsx        — шапка + центральный тумблер Карта/Камера
    MapView.tsx       — окно карты: pan/zoom/pinch, кнопки, чипы
    CameraView.tsx    — окно камеры: демо-рендер / video, снимок, fullscreen
    Customizer.tsx    — панель кастомизации
```

## Дальше (мост ROS 2)

`simulator.ts` — изолированный источник данных. Следующий шаг — узел-мост
(`ros2_ws/src/rus_slam_gui_bridge`): `tf2` (pose), `sensor_msgs/LaserScan`,
`nav_msgs/OccupancyGrid`, камера (WebRTC/MJPEG) → WebSocket, и GUI переходит
с демо-режима на живые данные без изменения интерфейсов.
