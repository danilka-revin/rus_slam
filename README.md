Проект разработан в строгом соответствии с требованиями конкурсного задания № 2: **«Автономное роботизированное устройство для внутренней логистики Научно-технического центра (НТЦ) АО «АВТОВАЗ»»** ([Регламент соревнований](https://pervye-events.hb.ru-msk.vkcloud-storage.ru/projects/documents/aac931ed623a48abb28c4cf1d844b4da.pdf)).

## 🏗 Архитектура системы управления

Комплекс построен по двухуровневой иерархической схеме:
1. **Верхний уровень:** Промышленный бортовой компьютер под управлением **Ubuntu 24.04/26.04 LTS** со стеком **ROS 2**. Обеспечивает SLAM-картографирование, планирование глобальных и локальных траекторий (Nav2), распознавание дорожных знаков и светофоров с помощью нейросетей компьютерного зрения, а также преобразование желаемых скоростей $(V_x, V_y, \omega_z)$ в углы и скорости 4 поворотных модулей.
2. **Нижний уровень:** 4 независимых контроллера поворотно-тяговых модулей (**Arduino Mega Pro Embed**), каждый из которых контролирует:
   - Шаговый двигатель поворота NEMA 23 через TB6600 с плавным S-образным профилем;
   - Силовой 3-фазный мост MOSFET мотор-колеса с 6-ступенчатой трапецеидальной коммутацией по встроенным датчикам Холла;
   - Защиту по перегрузке, калибровку начального угла и сторожевой таймер (Watchdog).

## 📐 Сборка поворотного модуля (Swerve Pod)

Конструкция каждого из 4 модулей обеспечивает восприятие огромных радиальных и осевых нагрузок без риска деформации рамы:

![Конструкция модуля](docs/images/pod_assembly.svg)

### Ключевые особенности узла:
- **Рама:** Сварная из стальной профильной трубы 40×40×2 мм (Ст3сп);
- **Опорно-поворотный узел:** Автомобильная ступица Subaru с двухрядным подшипником;
- **Передача:** Зубчатый ремень HTD 5M (ширина 15 мм) с передаточным числом $1:7.5$ ($z_1=16, z_2=120$);
- **Поворотный привод:** NEMA 23 (1.9 Н·м) &rarr; крутящий момент на модуле **13.68 Н·м** (запас по моменту трения $>3.6\times$);
- **Тяговый привод:** Бесщеточное мотор-колесо 10 дюймов от самоката на поворотной стальной вилке.

## 🔄 Кинематика крабового хода (4WIS / 4WID)

Шасси робота позволяет реализовать любые типы перемещений на плоскости:

![Кинематика крабового хода](docs/images/kinematics_diagram.svg)

1. **Крабовый ход (Crab Walk):** Все 4 колеса ориентируются в одном направлении $(\delta_1 = \delta_2 = \delta_3 = \delta_4 = \theta)$. Робот перемещается диагонально или строго вбок без изменения курсового угла.
2. **Разворот на месте (Zero-Radius Spin):** Все колеса ориентируются по касательным к окружности описания шасси. Разворот происходит вокруг геометрического центра с радиусом $R = 0$.
3. **Криволинейное движение (Ackerman / Omnidirectional Trajectory):** Согласованное управление углами и скоростями для плавного огибания препятствий.

## ⚡ Принципиальная схема платы модуля управления

Каждая из 4 плат объединяет цифровую логику, драйвер TB6600 и силовую силовую часть 3-фазного моста:

![Схема платы модуля](docs/images/module_circuit.svg)

### Назначение функциональных узлов платы:
- **ATmega2560:** Аппаратная обработка прерываний датчиков Холла, генерация частоты шага PUL/DIR, обмен с Ubuntu по UART (115200 бит/с с контрольной суммой CRC16).
- **TB6600:** Деление шага 1/8 (1600 имп/об), ограничение фазного тока 2.8 А.
- **MOSFET инвертор:** 6 транзисторов IRFB4110 (100V 180A, 4.5 мОм), полумостовые драйверы FD6288/IR2101, снабберная защита и датчик тока.

## 🚀 Инструкция по сборке и запуску ПО

### 1. Прошивка плат Arduino Mega Pro
1. Откройте файл [`firmware/module_controller/module_controller.ino`](firmware/module_controller/module_controller.ino) в среде Arduino IDE.
2. Для каждого из 4 модулей задайте константу `#define MODULE_ID` (1 для FL, 2 для FR, 3 для RL, 4 для RR).
3. Выберите плату **Arduino Mega or Mega 2560** и порт подключения `/dev/ttyUSB0`...`/dev/ttyUSB3`.
4. Загрузите прошивку в микроконтроллеры.

### 2. Запуск узла управления крабовым ходом в ROS 2 (Ubuntu)
```bash
# Клонирование и переход в рабочую область
cd ~/rus_slam

# Установка прав на исполнение скрипта узла
chmod +x ros2_ws/src/crab_drive_controller/crab_drive_node.py

# Предоставление прав на последовательные порты
sudo usermod -a -G dialout $USER
sudo chmod 666 /dev/ttyUSB*

# Запуск ROS 2 ноды кинематики крабового хода
python3 ros2_ws/src/crab_drive_controller/crab_drive_node.py
```

### 3. Тестирование движения публикацией команды скорости
```bash
# Движение вперед со скоростью 1.0 м/с
ros2 topic pub --once /cmd_vel geometry_msgs/msg/Twist "{linear: {x: 1.0, y: 0.0, z: 0.0}, angular: {z: 0.0}}"

# Крабовый ход: диагональное движение под 45 градусов
ros2 topic pub --once /cmd_vel geometry_msgs/msg/Twist "{linear: {x: 0.7, y: 0.7, z: 0.0}, angular: {z: 0.0}}"

# Разворот на месте с нулевым радиусом (вращение вокруг центра)
ros2 topic pub --once /cmd_vel geometry_msgs/msg/Twist "{linear: {x: 0.0, y: 0.0, z: 0.0}, angular: {z: 1.0}}"
```
